Mobile Menu Test

Resize your browser to mobile size or use mobile device to test the hamburger menu.

The mobile menu should appear when screen width is less than 768px.

Test Instructions:

  1. Resize browser to mobile width (< 768px)
  2. Click the hamburger menu button (☰)
  3. Menu should slide in from the right
  4. Click outside or on a menu item to close
  5. Press Escape key to close menu
